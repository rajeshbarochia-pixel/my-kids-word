અસલ ગુજરાતી અવાજ કેવી રીતે ચાલુ કરવો?

જો અવાજ અંગ્રેજી જેવા લહેકામાં અથવા અજીબ આવતો હોય તો આ સેટિંગ કરો:

🤖 એન્ડ્રોઇડ (Android) મોબાઈલ માટે:

  1. તમારા ફોનની Settings (સેટિંગ્સ) માં જાઓ.
  2. System ➔ Language & Input ➔ Text-to-Speech (અથવા સર્ચમાં "Text to speech" લખો) પર ક્લિક કરો.
  3. Preferred Engine ની બાજુમાં આવેલા સેટિંગ્સ આયકન પર ક્લિક કરો ➔ Install Voice Data પસંદ કરો.
  4. ત્યાંથી Gujarati (India) અથવા ગુજરાતી (ભારત) શોધીને અવાજ ડાઉનલોડ (Download) કરી લો.

🍎 આઇફોન (iPhone / iOS) માટે:

  1. આઇફોન ના Settings ➔ Accessibility માં જાઓ.
  2. Spoken Content ➔ Voices પર ક્લિક કરો.
  3. ત્યાંથી Gujarati પસંદ કરીને સિસ્ટમ વોઇસ (Lekha) ડાઉનલોડ કરી લો.
